# folio — Local PDF Studio

**Every PDF tool you need, running entirely on your own computer.**
No cloud. No account. No upload. Free forever.

Merge, split, compress, protect, watermark, **redact** and **OCR** — all offline.

[Get the source on GitHub](https://github.com/ssanidhya0407/folio) ·
[Privacy Policy](privacy)

---

## It cannot go online

Not "we promise not to" — there is no networking code in the application at
all, and the build fails if any is ever added. The Microsoft Store package
declares no network capabilities, so Windows enforces it too.

[How to verify that yourself](https://github.com/ssanidhya0407/folio#-the-offline-guarantee)

## Redaction that actually redacts

Most editors draw a rectangle over the text and leave the text in the file, one
*select-all → copy* away. folio deletes the glyphs and images underneath from
the content stream, then draws the box.
